# soldering-exercise
provide practice for novice solderers with several levels of difficulty

a single board with 2 alternative circuits:

- SAO connector/battery holder, 2 LEDs + 2 resistors

- trickier: SAO connector/battery holder, 555 timer + 2 capacitors + 4 resistors + 2 LEDs

with through-hole and surface-mount pads for each component
